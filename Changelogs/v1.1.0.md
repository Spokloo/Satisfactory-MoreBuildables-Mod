## Version 1.1.0

**Version number:** `v1.1.0`\
**Released on:** `29/06/2026`

[![github repo url](https://img.shields.io/badge/github-gray?style=for-the-badge&logo=github)](https://github.com/Spokloo/Satisfactory-MoreBuildables-Mod)

### Changes

- Updated Coated Concrete Quarter Foundations icons.
- Added Corner Ramp Extensions Pack (1m, 2m, 4m) for all materials.
- Added Inverted Corner Ramp Extensions Pack (1m, 2m, 4m) for all materials.
- Updated the mod icon. Made by [**Arclux Studios**](https://arcluxstudios.com).

### Fixes

- [#6](https://github.com/Spokloo/Satisfactory-MoreBuildables-Mod/issues/6): Fixed Half Foundations meshes to align with Quarter Foundations. Half Foundations now actually align with the center of a regular foundation.
- [#8](https://github.com/Spokloo/Satisfactory-MoreBuildables-Mod/issues/8): Fixed wrong collision profile for Quarter Foundations. Now set to `BuildingMesh` to match other in-game foundations.

### Known bugs

- [#9](https://github.com/Spokloo/Satisfactory-MoreBuildables-Mod/issues/9): Inverted Inner/Outer Corner Ramps don't show the FICSIT material when it is the first unlocked foundation within its subcategory. If you encounter this bug, unlock another type of foundation in the same subcategory and it should fix itself.
